# Чудовий ранок — сайт кав’ярні

Статичний адаптивний сайт на HTML, CSS і JavaScript для публікації через GitHub Pages.

## Як опублікувати
1. Створи новий **Public** репозиторій на GitHub, наприклад `chudovyi-ranok`.
2. Завантаж у корінь репозиторію `index.html`, `style.css`, `script.js`, папку `assets` та `.nojekyll`.
3. У репозиторії відкрий **Settings → Pages**.
4. У розділі **Build and deployment** вибери **Deploy from a branch**.
5. Обери гілку `main` і папку `/(root)`, натисни **Save**.
6. Дочекайся публікації та відкрий адресу, яку покаже GitHub Pages.

## Перед передачею власнику
- Погодити справжні фото, меню, ціни та графік роботи.
- Перевірити точну адресу/пін на карті.
- Переконатися, що власник дозволяє використовувати бренд і фото.
- Передавати власнику доступ до репозиторію та хостингу окремо; не публікувати паролі, токени чи приватні дані.

Instagram у сайті зараз веде на `@chudovyi_ranok_dusha`. Зображення `assets/cafe-morning.png` — згенерована концептуальна фотографія, а не підтверджене фото реального закладу. Заміни її на фото кав’ярні перед фінальною комерційною передачею.
