# Чудовий ранок — концепт сайту кав’ярні

Адаптивний сайт на HTML, CSS і JavaScript для GitHub Pages.

## Оновити вже створений GitHub-репозиторій
1. Розпакуй архів на пристрої.
2. Відкрий репозиторій `chudovyi-ranok` на GitHub.
3. Для кожного файлу, який треба оновити, відкрий його та натисни олівець **Edit** або видали старий і завантаж новий через **Add file → Upload files**.
4. Переконайся, що `index.html`, `style.css`, `script.js`, `.nojekyll` лежать у корені репозиторію, а `cafe-morning.png` і `favicon.svg` — у папці `assets/`.
5. Підтверди зміни кнопкою **Commit changes**.
6. Перевір сайт за опублікованим посиланням; GitHub Pages може оновлюватися кілька хвилин.

## Перед комерційною передачею
- Погодити справжні фото, меню, ціни, години роботи та точну адресу/пін на карті.
- Переконатися, що власник дозволяє використовувати бренд і фото.
- Узгодити кількість правок, дату передачі та оплату.
- Передати доступ до репозиторію/хостингу без передачі особистих паролів.

## Важливо
Зображення `assets/cafe-morning.png` — згенерована концептуальна фотографія, а не підтверджене фото закладу. В меню показані категорії, а не повний підтверджений прайс. Це демо-концепт до погодження з власником. Instagram-кнопки ведуть на `@chudovyi_ranok_dusha`.
